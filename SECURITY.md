# Security

Please do not publish security vulnerabilities, exploit details, API keys, access tokens, private scripts, or sensitive logs in a public GitHub issue.

Private vulnerability reporting is enabled. Use the repository's [Security tab](https://github.com/feelalright-dev/glowstone-b-roll-alpha/security) and select **Report a vulnerability** to send a private report.

If you cannot access that form, email [support@feelalright.dev](mailto:support@feelalright.dev) to request private-reporting instructions. Do not include vulnerability details, API keys, access tokens, or other secrets in that initial message.

This repository contains documentation only. The application source code is maintained privately.
